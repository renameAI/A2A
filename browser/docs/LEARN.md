# 학습 모드 — 링크 하나로 학습 틀

즐겨찾기 **학습**(`a2a://학습`)을 엽니다. 코드는 `learn/index.js`(엔진)와 `renderer/src/Learn.jsx`(화면)에 있습니다.

## 틀 (7단계)

| 단계 | 하는 일 | 근거 |
|---|---|---|
| 1. 지도 | 링크의 목차를 읽어 장별 과정을 만든다. 장마다 목표·예상 시간·왜 중요한지를 적고, 서문·용어집 같은 장은 건너뜀으로 표시한다 | 목표가 분명해야 읽는 것이 남는다 |
| 2. 예측 | 장마다 읽기 전 질문 2~3개를 주고, 예측은 메모에 적는다 | 사전 질문(pretesting) 효과 |
| 3. 읽기 | 원문을 옆 탭으로 연다 | — |
| 4. 인출 | 원문을 덮고 내 말로 퀴즈에 답한다. 채점은 모범 답을 통째로 주지 않고 빠진 고리를 짚는다 | 인출 연습(retrieval practice) |
| 5. 연결 | 연결한 프로젝트에서 이 장의 개념이 쓰인 실제 파일·함수를 찾아, 앱 안에서 그 줄을 연다 | 정교화(elaboration) |
| 6. 적용 | 내 프로젝트에 직접 해 볼 과제를 하고, 튜터의 "과제 검토"로 보여 준다 | 전이(transfer) |
| 7. 복습 | 맞히면 다음 상자, 틀리면 처음 상자로 간다. 상자별로 1·3·7·16·35일 뒤 다시 나온다 | 간격 반복(라이트너 상자) |

## 우리 코드와의 연결은 확인한 것만 남긴다
1. 모델이 프로젝트 지도(파일과 최상위 함수 이름만, 내용은 보내지 않음)에서 후보를 고른다.
2. 그 파일에 그 이름이 실제로 있는지 코드로 확인한다.
3. 후보의 **실제 코드**를 다시 읽혀서, 이 장의 개념과 이어지는 것만 남긴다. 설명은 코드에 근거해 쓰고, "추정" 같은 표현은 쓰지 않는다.

## 튜터 모드
- **질문:** 학습자가 묻는 것에 답한다.
- **코드로 설명:** 원문 개념 → 코드의 어느 줄 → 왜 그렇게 했는지 순서로 설명한다.
- **질문으로만:** 소크라테스식이다. 설명하지 않고 한 번에 질문 하나만 하며, 막히면 힌트를 하나 준다.
- **과제 검토:** 잘한 점, 고칠 점, 완료 조건 충족 여부를 본다.

## 기록
학습 활동(과정, 학습 카드, 답, 튜터 대화, 진도)은 수집 로그에 `learn.*`로 남는다. 업무 지도에서는 "학습" 플랫폼의 활동으로 보인다.
