# 브라우저 기본기 마일스톤

규칙: 구현 → 빌드 → 자체 시험 통과 → 체크. 전부 끝나면 에이전트 포함 전체 시험 + 앱 재시작.

## A. 아바타 색 서버 반영 (진행 중이던 것)
- [x] A1. dev DB에 v3 마이그레이션 적용, 엔진 재시작, /me가 avatar_hue 반환
- [x] A2. 앱: 색 저장을 서버로(PATCH /me), 모든 아바타가 팀원의 서버 색을 쓰게
- [x] A3. 자체 시험: 색 바꾸기 → 서버 반영 확인 → 원래대로

## B. 페이지 내 찾기 (⌘F)
- [x] B1. 메인: findInPage IPC + 결과(몇 번째/총 몇 개) 전달
- [x] B2. 셸: 찾기 바(카드 위), Enter 다음 · Shift+Enter 이전 · Esc 닫기
- [x] B3. 자체 시험: 픽스처 페이지에서 찾기 → 일치 수 확인

## P. 비밀번호 안전 저장 (핵심 · 로컬 우선)
원칙: macOS 키체인 보호 키로 암호화(safeStorage) · 평문 대체 저장 없음 · 에이전트는 절대 못 봄 · 채우기는 사용자가 눌러서, 주소가 정확히 같을 때만
- [x] P1. 페이지 읽기(에이전트)에 비밀번호 값이 절대 안 들어가게 — 지금 구멍 막기
- [x] P2. 금고(vault.js): 암호화 파일 저장·목록·삭제, 암호화 불가면 저장 거부
- [x] P3. 로그인 감지: 격리 월드에서 제출을 잡고(페이지는 위조 불가한 신호), 메인이 값을 가져감
- [x] P4. "저장할까요?" 안내 줄(저장 / 안 함 / 이 사이트는 안 함)
- [x] P5. 채우기: 저장된 사이트의 로그인 폼이면 안내 줄 → 눌러서 채우기
- [x] P6. 마이페이지 "저장된 비밀번호": 목록 · 보기(Touch ID/확인) · 삭제
- [x] P7. 자체 시험: 로그인 픽스처로 저장→다시 열기→채우기, 파일에 평문 없음, 에이전트 읽기에 비밀번호 없음
