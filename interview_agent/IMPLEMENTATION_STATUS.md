## 실제 API 실행 전 확인 사항

자동 테스트에서는 비용과 외부 상태 변경을 막기 위해 Friendli 및 Google API를 호출하지 않았다.

실제 수동 테스트 전 다음이 필요하다.

1. `.env.example`을 `.env`로 복사한다.
2. 네 개 환경변수에 실제 값을 넣는다.
3. 실행 파일 상단에서 `TARGET_COMPANY`를 테스트 기업으로 변경한다.
4. 첫 실제 실행은 결과 폴더가 비어 있는 상태에서 한 기업만 사용한다.
5. Google Grounding 출처 확인 로그와 최종 `strategy_ready` 상태를 함께 검토한다.

## 의도적으로 남긴 정책

- 질문 수보다 핵심 항목의 정확한 확인을 우선하며, 확인되지 않은 실행 세부값은 모델이 임의 완성하지 않는다.
- 품질 합격 수치는 실제 인터뷰 결과를 축적한 뒤 정하며 현재 코드에는 고정하지 않는다.
- 핵심 앵커가 모두 확인되어도 실행 제약이 남으면 `strategy_ready=false`가 정상이다.
- 비교 트랙 B를 활성화하면 B의 핵심 관계가 비어 있는 동안 `strategy_ready=false`다.
- 스키마 검증 통과는 실행 준비 완료와 같은 의미가 아니다.
