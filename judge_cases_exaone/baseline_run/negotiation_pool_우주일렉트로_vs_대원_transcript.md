# 협상 로그 [pool] — 우주일렉트로(판매) ↔ 대원(구매)

## R1 판매자
귀사의 품질 기준. 저희 우주일렉트로는 초정밀 커넥터 분야에서 검증된 기술 기반을 바탕으로 소량 PoC를 통해 성능을 입증해 드릴 수 있습니다.

## R1 구매자
소량 PoC 제안은 리스크 측면에서 유리하지만, 우선 구조적 게이트를 확인하고 싶습니다. ISO/TS 16949 인증과 층간소음 성능 KS F 2221 인증, 베트남 CE 기반 안전 인증을 이미 보유하고 있는지, 그리고 기존 계약이나 캐파 제약 없이 PoC를 수행할 수 있는 구조적 준비가 되어 있는지 알려 주세요.

## R2 판매자
귀사의 구조적 우려, 정확히 공감합니다. 저희는 ISO/TS 16949 인증을 보유하고 있으며, 베트남 생산 거점에서도 CE 기반 안전 인증을 충족하는 PoC 납품이 가능합니다. 층간소음 성능 KS F 2221은 현재 적용 대상이 아니나, 필요 시 별도 검증 경로를 마련할 수 있습니다. 우선 소량 PoC를 15일 이내 납품해 드릴 수 있도록 제안드립니다.

## R2 구매자
PoC 제안은 리스크 완화 측면에서 긍정적이지만, 기술 기반에 대한 실재성과 검증 경로가 명확하지 않아 신뢰 측면에서 갭이 있습니다. 구체적으로 어떤 실증 데이터나 검증 경로를 제시할 수 있는지, 그리고 과거 유사 프로젝트에서의 층간소음 성능 입증 사례가 있는지 확인 부탁드립니다.

## R3 판매자
귀사의 구조적 게이트 확인 요청, 정확히 복창합니다. 저희는 ISO/TS 16949 인증과 베트남 CE 기반 안전 인증을 보유하고 있으며, 층간소음 성능은 필요 시 별도 검증 경로를 마련할 수 있습니다. PoC 가능성을 위해 15일 이내 소량 납품을 제안드립니다.

## R3 구매자
PoC 제안은 구조적 게이트와 리스크 완화 측면에서 긍정적이지만, 계약 보호 측면에서 IP 소유권, NDA 체결 순서, 검증 후 독점 범위 등 법적 보호 장치가 명시되지 않아 갭이 있습니다. 제안서에 포함된 계약 보호 프레임워크와 PoC 검증 후 기술 활용 권한 범위를 구체적으로 제시해 주시기 바랍니다.

## R4 판매자
귀사의 구조적 게이트 확인 요청, 정확히 공감합니다. 저희는 ISO/TS 16949 인증과 베트남 CE 기반 안전 인증을 보유 중이며, PoC 검증 경로는 15일 이내 소량 납품과 함께 NDA 체결 후 기술 데이터 접근이 가능하도록 설계되어 있습니다. IP 소유권은 PoC 기간 동안 고객 소유로 이전하지 않으며, 검증 후 단계적 계약 전환을 제안드립니다.

## R4 구매자
PoC 제안이 구조적 게이트와 리스크 완화 측면에서 긍정적이지만, 성능 입증을 위한 실증 데이터나 검증 경로가 제시되지 않아 신뢰 측면에서 갭이 있습니다. 구체적으로 어떤 실증 데이터나 검증 경로를 제시할 수 있는지, 그리고 과거 유사 프로젝트에서의 층간소음 성능 입증 사례가 있는지 확인 부탁드립니다.

## R5 판매자
귀사의 구조적 게이트 확인 요청, 정확히 공감합니다. 저희는 ISO/TS 16949 인증과 베트남 CE 기반 안전 인증을 보유 중이며, 층간소음 성능은 필요 시 별도 검증 경로를 마련할 수 있습니다. 우선 15일 이내 소량 PoC 납품과 함께 NDA 체결 후 기술 데이터 접근이 가능하도록 설계되어 있습니다.

## R5 구매자

## R6 판매자

PoC 검증 후 단계적 계약 전환을 제안드리며, 검증 데이터와 함께 NDA 체결 후 접근 가능한 실증 경로를 함께 제시해 드리겠습니다.

## R7 판매자
귀사의 구조적 게이트 확인 요청, 정확히 공감합니다. 저희는 연간 1,200만 개 생산 캐파 기반으로 기존 계약 없이 즉시 PoC 대응이 가능하며, 15일 이내 납품은 자원 유연성과 내부 설비 가용성으로 실현 가능합니다. PoC 검증 경로는 NDA 체결 후 실증 데이터 접근을 통해 투명하게 공유드리겠습니다.
