# 판단 품질 비교 — Gemini판(judge_cases) vs K-EXAONE판(judge_cases_exaone)

> **방법**: 같은 회사 풀·같은 온톨로지·같은 조정 규칙 조건에서 동일한 두 쌍을 양 판으로
> 각각 완주시켜 결정·조건·근거·전개·형식 안정성을 대조. (쌍당 각 1회 실행 — §5 한계 참조)
> **실행일**: 2026-07-27 | 세션 4건 전부 스키마 검증 통과.

## 2. 일치하는 것 — 판단의 골격

- **구매자 핵심 결정은 4/4 모두 conditional 로 일치.** 양 백엔드가 같은 정보에서 같은
  결론 방향에 도달한다 — 온톨로지가 판단 골격을 지배하고 모델은 그 실행자라는 설계
  의도가 백엔드 교체 실험으로 재확인됨.
- 조건의 **구체성도 동급**: 양쪽 모두 "무엇을(인증·데이터·보증안) 어떻게 확인하는가
  (채점 방법)"가 붙은 실행 가능한 조건을 산출했다.
- 판매자 outcome 은 서로 다르지만 전부 인접 라벨(meeting/poc/deal_structured — 모두
  '비종결 긍정' 대역). 같은 백엔드의 반복 실행에서도 관측되는 수준의 변동이다
  (성능평가 보고서 §2.3).

## 3. 갈리는 것 — 전개 방식과 형식 안정성

### 3.1 결단력: Gemini 2라운드 종결 vs EXAONE 7라운드 상한 소진
가장 큰 행동 차이. Gemini 구매자는 핵심 조건이 식별되면 **스스로 `decide` 를 선언**
(2라운드)하고 나머지를 조건으로 넘긴다. EXAONE 구매자는 두 실행 모두 라운드 상한(7)까지
같은 요구를 심화 반복하며 결정을 유보했다 — 결정은 상한 소진 후 최종 판정 단계에서야
내려졌다. 결과적으로:
- EXAONE판은 호출 수 2.3~2.8배, 협상 시간 수 배.
- 단, EXAONE 의 신중함이 리스크 표기(8~10건)로 이어져 **확인 리스크는 더 풍부**하다.

### 3.2 형식 안정성: Gemini 무개입 vs EXAONE 안전망 의존
- Gemini: 안전망 발동 없이 깨끗한 완주(쓰레기 토큰·열거형 이탈·반복 모두 0).
- EXAONE: 이번 세션들까지 누적으로 **11종 안전망**(비문자열 강등, 빈 응답 재시도,
  불리언/outcome/status 정규화, 배열 방어, 깨진 토큰 제거(키 포함), 반복·에코 재발화,
  stance 교차검증, rationale 재판정, 타임아웃)이 실제 결함에서 도출·가동됐다.
  안전망이 있으면 산출물 품질은 동급에 수렴하지만, **안전망 없이는 운영 불가** 수준.

### 3.3 서술 품질
- Gemini rationale: 인과가 매끄럽고("정직한 한계 공개 → 신뢰 → 조건부 수용") 문장 완성도 높음.
- EXAONE rationale: 사실관계는 정확하나 문장이 다소 끊기고, 드물게 판정 라벨이 후한
  경향(약속만으로 deal_structured — 단 rationale 에 '실제 제공 미확정'을 정직하게 명시).

## 4. 종합 판정과 권고

| 축 | 우세 |
|---|---|
| 핵심 결정 정확도(내적 정합) | **동급** (4/4 일치) |
| 조건·채점법 품질 | **동급** |
| 대화 효율(라운드·호출 수) | **Gemini** |
| 서술 완성도·형식 안정성 | **Gemini** |
| 리스크 식별 풍부함 | EXAONE |
| 데이터 주권·국내 모델 요건 | EXAONE (K-EXAONE 전용 엔드포인트) |

**권고**:
1. 판단 품질 자체는 온톨로지가 지배하므로 **어느 백엔드든 신뢰 골격은 유지**된다.
   비용·품질 균형만 보면 Gemini판이 우위.
2. 국내 모델 요건·데이터 주권·경진대회 제출이 목적이면 EXAONE판이 실전 투입 가능한
   수준으로 안정화되어 있다(안전망 필수 유지).
3. EXAONE판 개선 여지 1순위는 **구매자 결단 유도**: BUYER_SPEAK 규칙의 decide 조건을
   더 명시적으로("핵심 5개 basis 중 N개가 assumed 이상이고 2회 이상 같은 요구가 반복되면
   decide") 강화하면 라운드 소진 문제가 줄어들 것으로 예상.

## 5. 한계 (정직 고지)

- **표본 쌍당 1회**: 라운드 수·outcome 라벨은 같은 백엔드 안에서도 변동하는 지표다.
  §1 표의 차이 중 '결단력'은 두 쌍에서 일관돼 실제 경향일 개연성이 높지만, outcome
  라벨 차이는 표본 부족으로 우열 판단 불가.
- **정답 앵커 부재**: 두 판 모두 "실제로 옳은 판단"과의 대조가 아니라 내적 정합 비교다.
- 평가자가 시스템 구축자와 동일한 자기평가이며, EXAONE판 안전망은 개발 과정에서
  누적 조정된 반면 Gemini판은 상대적으로 초기 상태라는 비대칭이 있다.
