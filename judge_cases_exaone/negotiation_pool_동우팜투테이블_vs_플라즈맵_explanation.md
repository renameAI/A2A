# 협상 결론 설명서

## 1. 결론 요약

- **구매자 결정**: 조건부 동의(conditional)로 PoC 진행을 검토하되, 의료기기급 검증 데이터 또는 제3자 검증 기반 실증 데이터와 외부 인증 로드맵의 구체적 제출을 전제로 함. 
- **판매자 outcome**: PoC 제안은 수용되었으나, 핵심 검증 데이터 부재와 비용 절감 수치의 구체성 부족으로 인해 신뢰 기반은 미흡한 상태.

## 2. 판단 경로 (라운드별)

- **라운드 1**: 판매자가 공급 안정성과 수직계열화 기반 신선 도계육 공급을 강조했으나, 구매자의 1순위 구매이유인 **비용 절감**과의 정합성이 부족하다는 판단(BB1_purpose_fit, BB2_value_hierarchy). 특히 의료기기급 멸균 검증 데이터 제출 가능성에 대한.
- **라운드 2**: 판매자가 HACCP 인증 유지와 맞춤형 위생 검증 자료 제공을 약속했으나, 구매자는 이를 '검증 경로'로만 인식하고 **실재 입증 가능한 데이터** 부재를 핵심 장애 요인으로 지적(BB6_execution_gate, BB5_evidence).
- **라운드 3**: 판매자가 제3자 검증 경로와 실시간 공유를 제시했으나, 구매자는 여전히 **외부 인증 로드맵 또는 기준 충족 입증**을 요구하며, PoC의 신뢰 기반이 '가정'에 머무를 수 있음을 경고(BB6_execution_gate, BB8_trust).
- **라운드 4**: 판매자가 제3자 검증 경로와 외부 인증 로드맵 제시를 약속했으나, 구체적 일정이나 기관 명시 없이 **해소 경로 제시에 그침**. 구매자는 여전히 검증 경로의 실재성 부족을 문제 삼음(BB5_evidence, BB6_execution_gate).
- **라운드 5–7**: 판매자가 비용 절감을 핵심 구매이유로 정확히 인정하고, 수직계열화 기반 원가 통제 실적과 제3자 검증 경로를 제시했으나, **비용 절감 수치의 구체성 부족**과 **외부 인증 로드맵의 구체성 미흡**으로 인해 신뢰 기반은 여전히 미흡함(BB2_value_hierarchy, BB5_evidence, BB6_execution_gate).

## 3. 게이트 점검

- **BB6_execution_gate**: 구조적 미달은 아니나, **의료기기급 검증 데이터 미제출**로 인해 검증 경로는 존재하나 실재 입증 수준에 도달하지 못함. Dealbreaker는 아님.
- **BB8_trust**: HACCP 인증 유지 확인은 신뢰 가산 요소이나, 멸균 검증 데이터 제출 약속은 '검증 경로' 제시일 뿐 **실재 입증은 아님**. authenticity_gate 미통과.
- **SB9(선별)**: 착취 신호는 없으나, 검증 경로 요구는 정보 봉쇄 신호로 해석되며, 정보 선별적 제공을 요구하는 caution 수준.

## 4. 왜 이 결정인가 / 왜 다른 결정이 아닌가

- **채택 결정의 근거**: 구매자의 1순위 구매이유인 **비용 절감**을 판매자가 정확히 인식하고, PoC를 통한 단계적 검증과 제3자 검증 경로 제시로 리스크 완화 가능성을 인정함. 또한 판매자가 한계(의료기기급 데이터 미보유)를 공개하며 정직성 구조를 일부 충족함.
- **기각된 대안**: 
 - **conditional 대신 recommend/hold**: recommend는 검증 경로 제시가 충분하지 않으므로 신뢰 기반 부족, hold는 PoC 제안 자체를 거부하는 것으로 과도한 반응. 
 - **즉시 계약 체결**: 검증 경로 미확보 상태에서 실재 입증 데이터 부재로 인해 신뢰 기반 미흡. 
 - **대체재 전환**: 기존 대안(화학 멸균/UV 처리) 대비 전환비용 대비 우위 입증 없음(BB3_substitute).

## 5. 조건과 검증 계획

| 조건 | check_method | 확인 기준 |
|------|--------------|-----------|
| 의료기기급 멸균 검증 데이터 또는 동등한 수준의 제3자 검증 기반 실증 데이터 제출 | 제3자 인증 기관 또는 독립 실험실의 검증 보고서 제출 여부 확인 | 외부 기관의 검증 보고서 또는 인증 획득 증빙 |
| 단계적 확장 시 비용 효율성 유지에 대한 수치 기반 검증 경로 제시 | PoC 이후 확장 시 원가 절감률, 유지보수 비용, 공급 안정성 지표를 포함한 시뮬레이션 또는 과거 실적 데이터 제출 | 수치 기반 시뮬레이션 또는 실적 데이터 제출 |
| 외부 인증 로드맵 및 향후 인증 계획의 구체적 일정 공개 | 향후 12개월 내 인증 획득 로드맵 및 담당 기관 명시 여부 확인 | 인증 기관, 일정, 담당 부서 명시 |

## 6. 남은 가설

| 가설 | explore 렌즈 | evidence_needed |
|------|--------------|-----------------|
| 의료기기급 검증 데이터 대신 제3자 검증 로드맵과 PoC 기간 내 실시간 위생 프로세스 입증을 결합한 '검증 경로 패키지' 제시 | sell | 외부 인증 로드맵 또는 검증 기준 충족 입증 |
| PoC 이후 단계적 확장 시 원가 절감 수치(예: % 이상)를 PoC 검증 자료와 연계해 제시 | sell | 수직계열화 기반 원가 절감 실적 데이터 |
| 의료기기급 검증 데이터 부재를 '단계적 검증 로드맵'으로 전환하고 PoC를 첫 번째 검증 단계로 포지셔닝 | sell | 향후 6개월 내 외부 인증 로드맵 또는 검증 기준 충족 계획 |
