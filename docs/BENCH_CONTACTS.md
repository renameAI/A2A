`contacts`(ContactPath)와 `decision_structure` 축의 추출 품질. 골든셋
`app/eval/contact_golden.json`, 채점기 `app/eval/contact_bench.py`, 러너
`scripts/run_contact_bench.py`.

```bash
LLM_PROVIDER=openai python scripts/run_contact_bench.py --k 3
```

## 왜 이 축을 재는가

후보 기업을 찾아도 **어느 문으로 들어가는지** 없으면 리드가 아니라 목록이다.
이 축의 최대 위험은 분류 오류가 아니라 **환각** — 자료에 없는 "공식 사이트
문의 폼"을 회사 규모로 짐작해 만들면 사용자는 존재하지 않는 문을 두드린다.

## 방법론 근거

| 근거 | 가져온 것 |
|---|---|
| [LLM Abstention Can Be a Prompt Artifact](https://arxiv.org/html/2507.16199) (2025) | unknown은 **양방향으로** 오용된다 — 답이 자료에 있는데 회피(over-abstain), 없는데 단정(over-claim). 그래서 decision_structure는 정확도 하나가 아니라 3태 보정(정답/과잉단정/과잉회피)으로 잰다 |
| [FaithJudge](https://arxiv.org/abs/2505.04847) | 충실도 분리 측정 — 예측 value가 원문에 실재하는가(전사 계약) |
| MEDDIC (Champion/Economic/Technical Buyer) | 창구(role_hint)와 결정 주체(decision_structure)의 분리. C12가 이 구분의 근거 케이스: 창구는 調達企画課, 결정은 調達戦略会議 |

## 골든셋 설계 (12케이스)

- 접점 유형: URL 폼, 부서 메일, 전화, 협력사 포털, 창구 부서명(주소 없음), SNS DM
- **환각 트랩 4건**: 매출 규모만(C04), 빈 자료(C06), 카탈로그 다운로드 페이지
  (C07 — 홈페이지 존재 ≠ 접촉 경로), 시설 규모 서술(C10)
- 관련성 필터 1건: C08 — 공장 견학 신청(총무부)은 거래 접점이 아니다
- 결정구조: stated 5 / absent 7. 원칙 — **창구가 있다는 것과 누가 정하는지는
  다른 사실이다** (C03·C08). 앵커는 any-of(한국어 축 값과 원어 앵커의 표기 차)

## 결과 (GPT-5.6 Luna, 프로덕션 경로)

| 단계 | 접점 R/P | 환각 | role_hint | 결정구조 정확 | 과잉단정/회피 |
|---|---|---|---|---|---|
| Baseline | 0.750 / 0.857 | 1 | 0.25 | 0.667* | 0 / 1 |
| +창구 부서 허용·role 강제·전사 계약 | 0.875 / 0.875 | 1 | 0.20 | 0.917 | 0 / 0 |
| +원어 표기 강제 (value·role_hint) | **1.000 / 1.000** | **0** | **0.83~1.0** | 0.917 | 0 / 0 |

*Baseline 수치는 골드 결함 수정( C03 일관성, 원어 앵커 any-of) 후 재해석 포함.

k=3 안정성: 접점 1.000/1.000 3회 모두, role_hint 0.833~1.0.

### 각 단계에서 배운 것

1. Baseline의 최대 결함은 **번역**이었다. HARD_RULES(한국어 강제)가
   商品統括部→상품통괄부로 부서명을 번역해 전사 계약을 위반했다 — 번역된
   부서명으로는 메일이 닿지 않는다. 회사명과 같은 원어 예외를 접점에도 명시.
2. 주소 없는 창구("문의는 상품통괄부로")를 접점에서 버리고 있었다 — value
   정의가 "URL·주소·번호"로 좁아서. 부서명 자체가 value가 될 수 있게 확장.
3. 벤치 자체의 결함 2건을 먼저 고쳤다: C03 골드가 C08의 원칙(창구≠결정 주체)과
   모순, decision 앵커가 원어 단일이라 한국어 축 값과 매치 불가. **골드 수정과
   프롬프트 수정을 분리**하는 것이 이 반복의 규율이다 — 섞으면 무엇이 개선인지
   알 수 없다.
