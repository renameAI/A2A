# 교사 천장 측정 — E11 "교사 합치 0.399"의 판정이 뒤집힌 과정

**한 줄**: 0.399를 "낮다"고 읽고 학생을 의심했는데, 천장을 재보니 **교사 자신의 자기합치가
0.356~0.401**이었다. 학생은 이미 상한에 닿아 있었고, 진짜 결함은 **교사가 추출값의 20%를
빈칸으로 뱉는 것**이었다.

---

## 발단

E11(represent 증류, 1.2B FFN LoRA) 학습이 끝나고 평가가 이렇게 나왔다.

```
1) 스키마 유효율    : 39/40 (98%)
2) 교사 합치(핵심3) : 평균 0.399
3) 환각-stated율    : 4/82 (5%)
```

첫 반응으로 나는 "형식은 배웠지만 내용은 40%만 맞다"고 보고했다. **그 프레이밍이 틀렸다.**

`교사 합치`는 정답률이 아니라 **토큰 자카드**다:

```python
def _jaccard(a, b):
    A, B = _tok(a), _tok(b)
    return len(A & B) / max(1, len(A | B))
```

같은 뜻을 다른 단어로 쓰면 점수가 깎인다. 그리고 평가 스크립트 자신이 경고하고 있었다 —
*"교사 합치는 상한이 교사 품질(자기증류 한계). 환각-stated율만이 교사와 독립적인 절대 지표다."*

**상한을 모르면 0.399는 해석 불가다.** 그래서 천장을 쟀다.

## 측정 1 — 교사 자기합치 (천장)

같은 held 40곳에 교사(K-EXAONE-236B, quote 모드)를 재호출해 저장된 라벨과 비교했다.

| | 값 |
|---|---|
| **교사 자기합치** | **0.356** |
| E11 학생 합치 | 0.399 |
| 완전일치(≥0.99) | **1/40** |

**학생이 교사와 맞는 정도가, 교사가 자기 자신과 맞는 정도보다 높다.** 천장의 112%.

분포는 더 심했다 — `최소 0.000 · p25 0.032 · 중앙 0.333 · p75 0.578`. **하위 25%는 두 번
돌린 교사가 서로 거의 안 겹친다.**

그리고 `build_data.py`의 `_teacher_extract_quote` docstring은 이 교사를 **"결정적"**이라고
적어놨다. 40번 중 1번만 재현했으니 사실이 아니다 — "결정적"은 *절차가* 단일 호출이라는
뜻이었고, 출력은 `_retry_json`의 **`temperature=0.2`**로 뽑힌다.

## 측정 2 — 온도를 낮추면 나아지나 (한 번 실패한 측정)

첫 시도에서 temp=0.0이 **0.174**로 더 나빠졌다. 그런데 이건 내 계측 오염이었다 —
온도만 바꾼 게 아니라 `max_tokens`를 16384→4096으로 같이 줄였고 실제로 잘림 오류가 났다.
**변수를 두 개 바꾸고 하나 탓을 했다.**

`max_tokens`를 되돌리고, 두 조건 모두 "새 표본 2개끼리" 비교하도록 대칭을 맞춰 재측정:

| | temp 0.2 (현행) | temp 0.0 |
|---|---|---|
| 자기합치 평균 | 0.401 | 0.284 |
| 중앙값 | 0.400 | 0.161 |
| **빈 값 비율** | **20%** | **47%** |

**온도를 0으로 내리면 추출값의 절반이 공백으로 나온다.** 낮은 자카드의 원인은 "무작위성"이
아니라 **빈 값**이었다(빈 문자열끼리도 자카드 0).

## 진짜 결함 — 빈칸 섞인 응답이 학습 라벨이 된다

`build_data.py`의 교사 게이트는 이렇게 재시도한다:

```python
if any(_has_content(d.get(f, {}).get("value")) for f in TARGET_FIELDS):
    data = d
    break
```

**`any`다.** 세 필드가 *전부* 비어야 재시도하고, **2개만 비면 그대로 통과**한다.
현행 temp=0.2에서 빈 값이 20%이므로, 그만큼이 빈칸인 채로 E11의 정답지가 됐다.

E11의 0.399는 이제 완전히 설명된다 — **20% 비어 있는 교사를 충실히 재현한 값**이고,
교사 자신의 자기합치(0.401)와 사실상 같다. 학생 잘못이 아니다.

## 결론

| 판정 | 내용 |
|---|---|
| E11 학생 품질 | **상한 도달.** 재학습·더 긴 학습으로 안 오른다(loss도 스텝 70에서 평탄) |
| 병목 | **교사 라벨의 빈 값 20%** |
| 처방 | 게이트를 `any` → `all`로 바꾸고 라벨 재생성. 온도는 0으로 내리면 **악화**하므로 유지 |
| 부수 | `_teacher_extract_quote`의 "결정적" 주석은 사실과 다름 — 정정 필요 |

## 교훈

1. **천장 없는 상대 지표는 숫자가 아니라 착시다.** 0.399는 천장이 0.36이면 훌륭하고
   0.9면 형편없다. 같은 숫자가 정반대 결론이 된다.
2. **문서의 주장은 검증 대상이지 전제가 아니다.** "결정적"이라 적힌 함수가 40번 중 1번만
   재현했다.
3. **변수는 하나씩 바꾼다.** 온도와 max_tokens를 같이 바꾸고 온도를 탓할 뻔했다.
4. 이건 같은 날 세 번째 같은 계열의 사고다 — k-표본(분산↓·정확도↓), synth 길이 제약
   (부수효과 달성·목표지표 악화), IDF(분산 0.200→0.433·골든 top1 1.000→0.533).
   **대리 지표를 최적화하고 라벨 지표에서 확인하면 대개 나빠져 있다.**
